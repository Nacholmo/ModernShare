# Local stock image

Firmware is deliberately not distributed. Use your own C713 1.30 image:

```text
bytes: 2172416
SHA-256: 06133ed6bc6272f6b1ab9c784723d9259c71cb4ef88b3defb6ed36f4a4e66c9b
```

Pass its path with `scripts/build.py --stock`. You may keep a local copy in this
directory; firmware files are ignored by Git and rejected by the public-file audit.
